Nurkeldi Samuratov - Real time data analysis and desicion making assignment 

In this project, the stream data for the campus bus is synthesized. The system gets the vehicle location and passenger count every minute. I created a Python program that parses and validates the real-time stream data. I utilized the generator in Python because it is better when it comes to handling memory management.
Moreover, I created a local FastAPI API. It computes the occupancy class (for example, LOW or HIGH) and validates the data.
Requirments:
Pandas
FastAPI
pydantic
